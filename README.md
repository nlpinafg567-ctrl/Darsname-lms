# سامانه آموزشی درس‌نامه نقد احمدالحسن بصری

سامانه آموزشی رایگان و متن‌باز برای کتاب «درس‌نامه نقد احمدالحسن بصری» — رابط بین استاد و شاگرد.

🌐 **نسخه زنده:** https://nlpinafg567-ctrl.github.io/darsname-lms/

## امکانات

### 👨‍🎓 شاگرد
- ورود با نام + کد کلاس
- مطالعه ۲۰ فصل / ۱۲۸ درس کتاب با علامت «خوانده شد»
- خودآزمایی هر فصل (پرسش‌های کتاب + خودارزیابی + پاسخ نوشتاری)
- داشبورد شخصی: درصد پیشرفت، تسلط، روزهای متوالی مطالعه
- پرسش از استاد، مشاهده اطلاعیه‌ها
- کارکرد آفلاین (بدون اینترنت هم مطالعه ممکن است)

### 👨‍🏫 استاد
- داشبورد: تعداد شاگردان، میانگین پیشرفت و تسلط، فعال‌های هفته
- جدول شاگردان با جزئیات هر نفر (پیشرفت فصل‌به‌فصل + پاسخ‌های خودآزمایی)
- صندوق پرسش‌های شاگردان
- تنظیمات: آدرس وب‌اپ، کد کلاس، گذرواژه

## معماری (۱۰۰٪ رایگان)

- **فرانت‌اند:** همین صفحه `index.html` (بدون بک‌اند، روی GitHub Pages)
- **پایگاه داده:** گوگل‌شیت شما، از طریق Google Apps Script (پوشه `apps-script/`)
- داده‌ها اول روی دستگاه شاگرد ذخیره و با اتصال به اینترنت به شیت شما همگام می‌شود

## راه‌اندازی (برای استاد)

راهنمای گام‌به‌گام در `apps-script/راهنمای-راه‌اندازی.md`:

1. کد `lms_apps_script.js` را در Apps Script یک گوگل‌شیت تازه بچسبانید و تابع `setup` را اجرا کنید
2. Web app را Deploy کنید (Execute as: Me — Who has access: Anyone)
3. در سامانه (ورود استاد ← تنظیمات) آدرس `/exec` را وارد کنید

## حریم خصوصی

نام شاگردان فقط در شیت خصوصی شما ذخیره می‌شود و هیچ داده‌ای جای دیگری ارسال نمی‌گردد.
