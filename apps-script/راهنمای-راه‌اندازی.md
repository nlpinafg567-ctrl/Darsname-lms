# راهنمای راه‌اندازی سامانه آموزشی درس‌نامه نقد احمدالحسن بصری

این سامانه ۱۰۰٪ رایگان است: صفحه وب عمومی (لینک اشتراکی برای شاگردان) + گوگل‌شیت شما به‌عنوان پایگاه داده.

## گام ۱ — ساخت پایگاه داده (۵ دقیقه)

1. به Google Drive بروید و یک **Google Sheet تازه** بسازید (نام مثلاً: `سامانه درس‌نامه`).
2. از منو: **Extensions ← Apps Script**
3. کل محتوای فایل `lms_apps_script.js` را کپی کرده و جایگزین کد پیش‌فرض کنید.
4. ذخیره کنید (Ctrl+S)، نام پروژه مثلاً `Darsname LMS`.
5. از نوار ابزار، تابع **`setup`** را انتخاب و ▶️ اجرا کنید.
   - اولین بار گوگل اجازه می‌خواهد: Review permissions ← حساب خودتان ← Advanced ← Go to project ← Allow.
6. برگردید به شیت؛ شش شیت ساخته شده است. در شیت **Config** دو مقدار هست:
   - `teacherPassword` → گذرواژه ورود استاد (پیش‌فرض `1234` — حتماً عوض کنید)
   - `classCode` → کد کلاس برای ورود شاگردان (پیش‌فرض `QAEM1404` — می‌توانید عوض کنید)

## گام ۲ — انتشار وب‌اپ (۳ دقیقه)

1. در Apps Script: **Deploy ← New deployment**
2. آیکون چرخ‌دنده کنار Select type ← گزینه **Web app**
3. تنظیمات:
   - Description: `Darsname LMS v1`
   - **Execute as: Me**
   - **Who has access: Anyone**
4. **Deploy** ← اجازه دسترسی بدهید.
5. آدرس **Web app URL** (تمام‌شونده به `/exec`) را کپی کنید.

> ⚠️ اگر بعداً کد را ویرایش کردید، دوباره Deploy ← **Manage deployments** ← ✏️ ← **New version** بسازید تا تغییرات اعمال شود.

## گام ۳ — اتصال به سامانه (۲ دقیقه)

1. لینک سامانه را باز کنید و وارد بخش **استاد** شوید (گذرواژه پیش‌فرض `1234`).
2. **تنظیمات** ← آدرس Web app URL را بچسبانید + کد کلاس و گذرواژه دلخواه ← ذخیره.
3. تمام شد! از این پس:
   - شاگردان با **نام + کد کلاس** وارد می‌شوند؛ پیشرفتشان در شیت شما ثبت می‌شود.
   - داشبورد استاد با همان گذرواژه، داده‌ها را از شیت می‌خواند.

## مدیریت روزمره (بدون کدنویسی)

| کار | روش |
|---|---|
| دیدن پیشرفت شاگردان | داشبورد استاد در سامانه، یا مستقیم شیت‌های Progress و Quiz |
| اطلاعیه برای شاگردان | در شیت **Announcements** یک سطر تازه اضافه کنید (ستون text) |
| پاسخ به پرسش شاگرد | شیت **Questions**؛ بعد از پاسخ، ستون answered را TRUE کنید |
| افزودن/حذف شاگرد | شاگرد خودش با کد کلاس ثبت‌نام می‌کند؛ برای حذف، سطرش را از شیت Students پاک کنید |
| تغییر گذرواژه/کد کلاس | شیت Config |

## نکات

- بدون انجام گام ۲ و ۳ هم سامانه **آفلاین** کامل کار می‌کند (پیشرفت روی گوشی/مرورگر خود شاگرد ذخیره می‌شود)؛ فقط داشبورد استاد داده جمعی نمی‌بیند.
- همه‌چیز رایگان است؛ سهمیه رایگان Apps Script برای یک کلاس ۳۰–۱۰۰ نفره کافی است.
- نسخه پشتیبان: هر از گاهی از منوی File ← Download شیت را دانلود کنید.
